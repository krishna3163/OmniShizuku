# OmniShizuku

OmniShizuku — это открытая утилита для Android для рабочих процессов Shizuku, ADB и Dhizuku. Она предоставляет доступ к API системного уровня через службу Shizuku, с модулями для управления устройствами, автоматизации, оптимизаций и многого другого.

## Функции

### Центр основных функций
- **Dynamic Island** — Плавающий оверлей в виде пилюли от отверстия под камеру для прямых трансляций, батареи и уведомлений
- **Smart Pixels (Экономия AMOLED)** — Отключает 25–75% подпиксельной сетки OLED для экономии 15–44% энергии экрана
- **Регулятор дисплея** — Переопределение разрешения, плотности экрана (DPI) и частоты обновления
- **Принудительный темный режим** — Принудительная установка темной темы во всех установленных приложениях
- **Центр и охрана батареи** — Здоровье батареи в реальном времени, подсчет циклов, температура и охрана долговечности
- **Охрана карманного режима** — Защита от случайных нажатий в кармане с помощью датчиков близости и освещения
- **Безопасность экрана и разблокировка DRM** — Обход FLAG_SECURE для скриншотов в банковских и потоковых приложениях
- **Разрешения и AppOps** — Контроллер привилегированных разрешений и ограничений фоновых служб
- **Настройка SystemUI** — Черный список значков строки состояния, стили значков батареи и иммерсивный режим
- **Оптимизатор игр и процессора Axeron** — Профили производительности, нулевая задержка анимации и обрезка кэша
- **Принудительный Doze** — Агрессивная автоматизация глубокого простоя в режиме ожидания при выключенном экране
- **Расширенные элементы управления питанием** — Перезагрузка, восстановление, загрузчик, выключение и кнопка сна через оболочку
- **Контроллер приватного DNS** — Зашифрованные предустановки DNS без VPN (Cloudflare, AdGuard, Quad9, Google)
- **Обход привязки оператора** — Разблокировка точки доступа с ограничениями оператора
- **Сохраненные пароли Wi-Fi** — Чтение и отображение сохраненных точек доступа Wi-Fi и паролей
- **Shut Up! Глушитель медиа** — Приглушение звука медиа по приложениям
- **Мастер аудиопотоков** — Независимое управление громкостью для медиа, звонка, будильника, вызова
- **Переключение треков кнопками громкости** — Переключение треков с помощью кнопок громкости с выключенным экраном
- **Подсветка краев уведомлений** — Неоновая анимация свечения по периметру дисплея при уведомлениях
- **Автоматический DND (Режим дзен)** — Автоматизированное расписание «Не беспокоить» на основе фокуса приложения и расписаний
- **Caffeinate** — Сохранение экрана включенным с уведомлением остановки и плиткой быстрых настроек
- **Студия водяных знаков и EXIF** — Роскошная рамка Leica и минималистичный брендинг Hasselbak с живым EXIF
- **Универсальный удалитель Android (UAD)** — Удаление пакетов, ранжированное сообществом по безопасности, и восстановление одним нажатием
- **Замораживатель приложений** — Мгновенная заморозка фоновых приложений без удаления
- **Привилегированный файловый менеджер** — Просмотр защищенных системных путей и каталогов Android/data
- **Профессиональный установщик пакетов** — Установка разделенных APK, APKS, XAPK с флагами понижения версии и низкого SDK

### Автозаполнение PIN ADB по беспроводной сети (доступность)
- **Выключено** — Вводите PIN-код сопряжения самостоятельно
- **Ручной** — Менеджер сообщает, когда появляется диалог
- **Автоматический** — Служба доступности вводит сохраненный PIN-код в диалог «Сопряжение с устройством»
- Только с согласия пользователя — ничего не работает, пока вы не включите это в настройках

### Производительность и стабильность
- **Ленивое размытие движения** — Циклы Sampling-кадра работают только во время прокрутки, устраняя нагрузку процессора на каждый кадр
- **Crashlytics + обработчик необработанных исключений** — Сбои регистрируются, а не вызывают молчаливый вылет приложения
- **Защитный привязчик Shizuku** — Доступ к привязчику с проверкой на null для предотвращения вылетов NPE на Realme/OEM
- **Ограниченная загрузка информации об устройстве** — Тайм-аут 20 секунд на запросы dumpsys, отображение частичных данных вместо застрявшего спиннера

### Первичное введение при первом запуске
- 6 экранов отказа от ответственности (права, побочные эффекты владельца устройства, риски рута, поведение сторонних приложений, лицензия, предупреждения для банковских приложений)
- Соглашение с обратным отсчетом 5 секунд и флажком «Я прочитал и согласен»
- Выбор языка (система + 12 языков)
- Выбор темы (следовать системе / темная / светлая / черная ночь AMOLED / использовать цвет системы)
- Метод активации (беспроводная отладка / рут / подключение к компьютеру)

## Требования

- Android 5.0 (API 21) или выше
- Служба Shizuku запущена (через беспроводную отладку, рут или ADB)
- Разрешение Shizuku предоставлено приложению

---

## Установка

1. Установите APK из [GitHub Releases](https://github.com/krishna3163/OmniShizuku/releases)
2. Включите Shizuku на вашем устройстве (беспроводная отладка или ADB)
3. Предоставьте разрешение Shizuku приложению OmniShizuku
4. При первом запуске завершите процесс введения

---

## Сборка из исходного кода

```bash
git clone git@github.com:krishna3163/OmniShizuku.git
cd OmniShizuku
./gradlew :manager:assembleDebug
```

Отладочный APK будет в `manager/build/outputs/apk/debug/manager-debug.apk`.

## Безопасность

Это приложение запрашивает расширенные системные разрешения через Shizuku. Используйте ответственно:

- Не предоставляйте доступ ненадежным приложениям
- Беспроводная отладка и ADB раскрывают системные интерфейсы
- Доступ к руту обходит модель безопасности Android
- Режим владельца устройства может иметь побочные эффекты (ограничения сброса к заводским настройкам, ограничения удаления приложений)

См. полные сведения в отказе от ответственности при первом запуске.
