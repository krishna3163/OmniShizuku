# OmniShizuku

OmniShizuku — это открытая утилита для Android для рабочих процессов Shizuku, ADB и Dhizuku. Она предоставляет доступ к API системного уровня через службу Shizuku, с модулями для управления устройствами, автоматизации, оптимизаций и многого другого.

## Возможности

### Центр основных функций (Essentials Hub)
- **Dynamic Island** — Плавающий оверлей в виде капсулы у выреза экрана для медиа, батареи и уведомлений
- **Smart Pixels (Экономия AMOLED)** — Отключает 25–75% субпиксельной сетки OLED для экономии 15–44% энергии экрана
- **Display Tweaker** — Переопределение разрешения, плотности экрана (DPI) и частоты обновления
- **Принудительный темный режим** — Принудительное включение темной темы для всех установленных приложений
- **Центр и защита аккумулятора** — Мониторинг здоровья батареи в реальном времени, подсчет циклов, температура и защита долговечности
- **Защита в кармане (Pocket Mode)** — Защита от случайных нажатий с помощью датчиков приближения и освещения
- **Безопасность экрана и разблокировка DRM** — Обход ограничения FLAG_SECURE для создания скриншотов в банковских и стриминговых приложениях
- **Разрешения и AppOps** — Контроллер привилегированных разрешений и ограничение фоновых служб
- **Тюнер SystemUI** — Черный список значков строки состояния, стили значка батареи и режим погружения
- **Оптимизатор игр и CPU Axeron** — Профили производительности, нулевая задержка анимаций и очистка кэша
- **Принудительный Doze** — Агрессивная автоматизация глубокого сна (Deep Idle) при выключении экрана
- **Расширенное управление питанием** — Перезагрузка, Recovery, Bootloader, выключение и переход в сон через shell
- **Контроллер частного DNS** — Зашифрованные предустановки DNS без необходимости VPN (Cloudflare, AdGuard, Quad9, Google)
- **Обход ограничений раздачи интернета** — Разблокировка хотспота, ограниченного оператором
- **Сохраненные пароли Wi-Fi** — Чтение и отображение сохраненных точек доступа Wi-Fi и ключей безопасности
- **Shut Up! Глушитель звука медиа** — Отдельное отключение звука медиа для конкретных приложений
- **Мастер аудиопотоков** — Независимое раздельное управление громкостью каналов
- **Переключение треков кнопками громкости** — Переключение треков при выключенном экране с помощью кнопок громкости
- **Подсветка краев при уведомлениях** — Неоновая анимация свечения по периметру экрана при поступлении уведомлений
- **Авто-DND (Режим дзен)** — Автоматическое расписание режима «Не беспокоить»
- **Caffeinate** — Предотвращение отключения экрана с уведомлением остановки и плиткой в быстрых настройках
- **Студия водяных знаков и EXIF** — Премиальная рамка Leica и минималистичный стиль Hasselblad с живой полосой EXIF
- **Универсальный удалитель мусора Android (UAD)** — Удаление пакетов с учетом оценок безопасности сообщества и восстановление в 1 касание
- **Замораживатель приложений** — Мгновенная заморозка фоновых приложений без необходимости удаления
- **Привилегированный файловый менеджер** — Просмотр защищенных системных путей
- **Установщик пакетов Pro** — Установка разделенных APK-пакетов (Split APKs, APKS, XAPK)

### Дополнительные встроенные модули
- **Theme Patcher** — Кастомизация системной темы
- **Sound Master** — Продвинутое управление звуком
- **Mixed Audio** — Микширование звука и маршрутизация аудиопотоков
- **LookBack** — Запись и быстрое воспроизведение экрана
- **Universal PiP** — Режим «Картинка в картинке» для любого приложения
- **Intent Shell** — Выполнение shell-команд через широковещательные интенты
- **Local Shell** — Встроенный эмулятор терминала

### Беспроводной авто-PIN ADB (Специальные возможности)
- **Выключено** — Ручной ввод PIN-кода сопряжения
- **Вручную** — Менеджер оповещает о появлении диалогового окна
- **Автоматически** — Служба доступности вводит сохраненный PIN-код в окно «Подключение устройства»
- Только по желанию (Opt-in) — служба не запускается, пока не включена в Настройках

### Производительность и стабильность
- **Ленивое размытие движения (Lazy motion blur)** — Циклы сэмплирования работают только при прокрутке, устраняя нагрузку на процессор
- **Crashlytics + перехватчик исключений** — Сбои детально фиксируются вместо внезапного закрытия приложения
- **Защитная обертка Shizuku Binder** — Null-safe доступ к Binder для предотвращения падений с ошибкой NPE на Realme и других OEM-прошивках
- **Ограниченная по времени загрузка DeviceInfo** — Таймаут 20 секунд для запросов dumpsys, предотвращающий бесконечное зависание

### Первичное введение при первом запуске
- 6 экранов предупреждений (привилегии, последствия режима владельца устройства, риски root, поведение сторонних приложений, лицензия, предупреждения банков)
- Соглашение с 5-секундным таймером обратного отсчета и чекбоксом «Я прочитал и согласен»
- Выбор языка интерфейса (системный + 12 языков)
- Выбор темы оформления (системная / темная / светлая / черная ночь AMOLED / динамические цвета обоев)
- Выбор метода активации (беспроводная отладка / root / подключение к ПК)

## Системные требования

- Android 5.0 (API 21) или новее
- Работающая служба Shizuku (через беспроводную отладку, Root или ADB)
- Предоставленное разрешение Shizuku для приложения

---

## Установка

1. Загрузите и установите APK из раздела [GitHub Releases](https://github.com/krishna3163/OmniShizuku/releases)
2. Включите Shizuku на устройстве (через беспроводную отладку или ADB)
3. Предоставьте OmniShizuku разрешение Shizuku
4. При первом запуске пройдите шаги начального мастера настройки

---

## Сборка из исходного кода

```bash
git clone git@github.com:krishna3163/OmniShizuku.git
cd OmniShizuku
./gradlew :manager:assembleDebug
```

Готовый файл APK для отладки будет находиться по пути: `manager/build/outputs/apk/debug/manager-debug.apk`.

## Плитки быстрых настроек (Quick Settings Tiles)

В OmniShizuku включены плитки быстрых настроек для шторки уведомлений:
- Caffeinate (сохранение экрана включенным)
- Переключатель беспроводного ADB
- Запуск / остановка сервера Shizuku
- Переключатель режима маскировки (Stealth)

Чтобы добавить их, опустите шторку уведомлений и нажмите на значок редактирования (карандаш).

## Безопасность

Это приложение запрашивает расширенные системные привилегии через Shizuku. Используйте его ответственно:

- Не предоставляйте доступ ненадежным и непроверенным приложениям
- Беспроводная отладка и ADB открывают низкоуровневые системные интерфейсы
- Root-доступ обходит встроенную модель изоляции безопасности Android
- Режим владельца устройства (Device Owner) может накладывать системные ограничения (блокировка сброса до заводских настроек, невозможность удаления определенных приложений)

Ознакомьтесь с полным текстом дисклеймера при первом запуске.
