# OmniShizuku

OmniShizuku एक ओपन-सोर्स एंड्रॉइड यूटिलिटी है जो Shizuku, ADB, और Dhizuku वर्कफ़्लो के लिए है। यह Shizuku सेवा के माध्यम से सिस्टम-लेवल API एक्सेस प्रदान करता है, जिसमें डिवाइस प्रबंधन, ऑटोमेशन, ऑप्टिमाइज़ेशन, और बहुत कुछ शामिल है।

## सुविधाएँ (Features)

### एसेंशियल्स हब (Essentials Hub)
- **डायनामिक आइलैंड (Dynamic Island)** — लाइव मीडिया, बैटरी और अलर्ट के लिए फ्लोटिंग पंच-होल पिल ओवरले
- **स्मार्ट पिक्सेल (Smart Pixels - AMOLED Saver)** — 25–75% OLED सबपिक्सेल ग्रिड को डिसेबल करके 15–44% डिस्प्ले पावर बचाएं
- **डिस्प्ले ट्वीकर (Display Tweaker)** — रिज़ॉल्यूशन, स्क्रीन डेंसिटी (DPI), और रिफ्रेश रेट ओवरराइड
- **फोर्स डार्क मोड (Force Dark Mode)** — सभी इंस्टॉल किए गए ऐप्स में डार्क थीम लागू करें
- **बैटरी सेंटर और गार्ड (Battery Center & Guard)** — रियल-टाइम बैटरी स्वास्थ्य, साइकिल काउंट, तापमान और लॉन्गेविटी गार्ड
- **पॉकेट मोड गार्ड (Pocket Mode Guard)** — जेब में आकस्मिक टच से सुरक्षा के लिए प्रॉक्सिमिटी और लाइट सेंसर
- **स्क्रीन सिक्योरिटी और DRM अनलॉक (Screen Security & DRM Unlock)** — बैंकिंग और स्ट्रीमिंग ऐप्स में स्क्रीनशॉट के लिए FLAG_SECURE बायपास करें
- **परमिशन और AppOps (Permissions & AppOps)** — प्रिविलेज्ड परमिशन कंट्रोलर और बैकग्राउंड सर्विस लिमिट्स
- **सिस्टमUI ट्यूनर (SystemUI Tuner)** — स्टेटस बार आइकन ब्लैकलिस्ट, बैटरी आइकन स्टाइल और इमर्सिव मोड
- **Axeron गेमिंग और CPU ऑप्टिमाइज़र (Axeron Gaming & CPU Optimizer)** — परफॉर्मेंस प्रोफाइल, ज़ीरो एनिमेशन लेटेंसी और कैश ट्रिम
- **एन्फोर्स डोज़ (Enforce Doze)** — स्क्रीन ऑफ होने पर आक्रामक स्टैंडबाय डीप आइडल ऑटोमेशन
- **एडवांस्ड पावर कंट्रोल्स (Advanced Power Controls)** — शेल के माध्यम से रीबूट, रिकवरी, बूटलोडर, शटडाउन और स्लीप की
- **प्राइवेट DNS कंट्रोलर (Private DNS Controller)** — एन्क्रिप्टेड ज़ीरो-VPN DNS प्रीसेट (Cloudflare, AdGuard, Quad9, Google)
- **कैरियर टेदरिंग बायपास (Carrier Tethering Bypass)** — कैरियर-प्रतिबंधित हॉटस्पॉट अनलॉक करें
- **सेव्ड Wi-Fi पासवर्ड्स (Saved Wi-Fi Passwords)** — सेव किए गए Wi-Fi एक्सेस पॉइंट और पासवर्ड देखें
- **Shut Up! मीडिया म्यूटर (Shut Up! Media Muter)** — प्रति-ऐप मीडिया ऑडियो म्यूटिंग
- **ऑडियो स्ट्रीम मास्टर (Audio Stream Master)** — स्वतंत्र वॉल्यूम स्ट्रीम नियंत्रण
- **वॉल्यूम की ट्रैक स्किपर (Volume Key Track Skipper)** — स्क्रीन ऑफ होने पर वॉल्यूम बटन का उपयोग करके ट्रैक स्किप करें
- **नोटिफिकेशन एज लाइटिंग (Notification Edge Lighting)** — नोटिफिकेशन आने पर डिस्प्ले किनारों पर नियॉन ग्लो एनिमेशन
- **ऑटो DND (ज़ेन मोड) (Auto DND - Zen Mode)** — स्वचालित डू-नॉट-डिस्टर्ब शेड्यूलिंग
- **कैफ़िनेट (Caffeinate)** — स्टॉप नोटिफिकेशन और क्विक सेटिंग्स टाइल के साथ डिस्प्ले को सक्रिय रखें
- **फोटो वॉटरमार्क और EXIF स्टूडियो (Photo Watermark & EXIF Studio)** — लाइव EXIF स्ट्रिप के साथ लक्ज़री Leica फ्रेम और Hasselblad ब्रांडिंग
- **यूनिवर्सल एंड्रॉइड डेब्लोटर (UAD)** — कम्युनिटी सुरक्षा-रैंक आधारित पैकेज रिमूवल और 1-टैप रिस्टोर
- **ऐप फ्रीज़र (App Freezer)** — बैकग्राउंड ऐप्स को तुरंत फ्रीज़ करें
- **प्रिविलेज्ड फ़ाइल एक्सप्लोरर (Privileged File Explorer)** — सुरक्षित सिस्टम पाथ्स ब्राउज़ करें
- **पैकेज इंस्टॉलर प्रो (Package Installer Pro)** — स्प्लिट APKs, APKS, XAPK इंस्टॉल करें

### अतिरिक्त एकीकृत मॉड्यूल (Additional Integrated Modules)
- **थीम पैचर (Theme Patcher)** — सिस्टम थीम कस्टमाइज़ेशन
- **साउंड मास्टर (Sound Master)** — उन्नत ऑडियो नियंत्रण
- **मिक्स्ड ऑडियो (Mixed Audio)** — ऑडियो मिक्सिंग और रूटिंग
- **लुकबैक (LookBack)** — स्क्रीन रिकॉर्डिंग और प्लेबैक
- **यूनिवर्सल PiP (Universal PiP)** — किसी भी ऐप के लिए पिक्चर-इन-पिक्चर
- **इन्टेंट शेल (Intent Shell)** — इन्टेंट्स के ज़रिये शेल कमांड
- **लोकल शेल (Local Shell)** — बिल्ट-इन टर्मिनल एमुलेटर

### वायरलेस ADB ऑटो-पिन (एक्सेसिबिलिटी)
- **ऑफ़ (Off)** — पेयरिंग पिन स्वयं टाइप करें
- **मैनुअल (Manual)** — मैनेजर आपको बताता है कि डायलॉग कब आता है
- **ऑटोमैटिक (Automatic)** — एक्सेसिबिलिटी सेवा “Pair with device” डायलॉग में स्टोर किया गया पिन दर्ज करती है
- केवल ऑप्ट-इन — सेटिंग्स में सक्षम करने तक कुछ भी नहीं चलता

### परफॉर्मेंस और स्थिरता (Performance & Stability)
- **लेज़ी मोशन ब्लर (Lazy motion blur)** — फ्रेम-सैंपलर लूप केवल स्क्रॉलिंग के दौरान चलते हैं, प्रति-फ्रेम CPU बर्न समाप्त होता है
- **क्रैशलिटिक्स + अनकॉट हैंडलर (Crashlytics + uncaught handler)** — क्रैश रिकॉर्ड किए जाते हैं बजाय ऐप के चुपचाप बंद होने के
- **डिफेंसिव Shizuku बाइंडर (Defensive Shizuku binder)** — नल-सेफ बाइंडर एक्सेस Realme/OEM NPE क्रैश को रोकता है
- **डिवाइस इन्फो बाउंडेड लोडिंग (DeviceInfo bounded loading)** — dumpsys क्वेरी पर 20s टाइमआउट, अटके स्पिनर के बजाय आंशिक डेटा दिखाता है

### फर्स्ट-लॉन्च ऑनबोर्डिंग (First-Launch Onboarding)
- 6 डिस्क्लेमर स्क्रीन (प्रिविलेज, डिवाइस ओनर साइड इफेक्ट्स, रूट जोखिम, थर्ड-पार्टी व्यवहार, लाइसेंस, बैंक ऐप चेतावनियां)
- 5-सेकंड काउंटडाउन टाइमर और "मैंने पढ़ लिया है और सहमत हूँ" चेकबॉक्स के साथ समझौता
- भाषा चयन (सिस्टम + 12 भाषाएँ)
- थीम चयन (सिस्टम फॉलो करें / डार्क / लाइट / ब्लैक नाइट AMOLED / सिस्टम रंग का उपयोग करें)
- एक्टिवेशन विधि (वायरलेस डिबगिंग / रूट / कंप्यूटर से कनेक्ट करें)

## आवश्यकताएँ (Requirements)

- एंड्रॉइड 5.0 (API 21) या उच्चतर
- Shizuku सेवा सक्रिय हो (वायरलेस डिबगिंग, रूट, या ADB के माध्यम से)
- ऐप को Shizuku अनुमति दी गई हो

---

## इंस्टॉलेशन (Installation)

1. [GitHub Releases](https://github.com/krishna3163/OmniShizuku/releases) से APK इंस्टॉल करें
2. अपने डिवाइस पर Shizuku सक्रिय करें (वायरलेस डिबगिंग या ADB)
3. OmniShizuku को Shizuku अनुमति दें
4. पहली बार लॉन्च करने पर, ऑनबोर्डिंग प्रक्रिया पूरी करें

## सोर्स से बिल्ड करें (Building from Source)

```bash
git clone git@github.com:krishna3163/OmniShizuku.git
cd OmniShizuku
./gradlew :manager:assembleDebug
```

डिबग APK `manager/build/outputs/apk/debug/manager-debug.apk` पर मिलेगा।

## सुरक्षा (Security)

यह ऐप Shizuku के ज़रिये उच्च सिस्टम विशेषाधिकार प्राप्त करता है। ज़िम्मेदारी से उपयोग करें:

- अविश्वसनीय अनुप्रयोगों को एक्सेस न दें
- वायरलेस डिबगिंग और ADB सिस्टम इंटरफ़ेस को एक्सपोज़ करते हैं
- रूट एक्सेस एंड्रॉइड के सुरक्षा मॉडल को बायपास करता है
- डिवाइस ओनर मोड के दुष्प्रभाव हो सकते हैं (फ़ैक्टरी रीसेट प्रतिबंध, ऐप हटाने की सीमाएं)

पूरी जानकारी के लिए फर्स्ट-लॉन्च डिस्क्लेमर देखें।
